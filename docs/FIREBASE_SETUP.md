# מדריך הקמת Firebase — מוסדות ברכת אברהם

מדריך צעד-אחר-צעד להקמת ה-Backend. בסופו תעבירו לי 6 ערכי הגדרה, ואני מחבר את
האתר ואת פאנל הניהול ל-Firebase (Firestore + Storage + Authentication + Hosting).

> כל מה שמסומן **⇒ שלחו לי** — זה מה שאני צריך מכם. השאר זה לחיצות בקונסולה.

---

## שלב 1 — יצירת חשבון ופרויקט (5 דק')

1. היכנסו ל-<https://console.firebase.google.com> עם חשבון Google של המוסדות
   (מומלץ לפתוח חשבון Gmail ייעודי, למשל `birkatavraham.office@gmail.com`, שיהיה
   בבעלות המוסדות ולא אישית).
2. לחצו **"Create a project"** (יצירת פרויקט).
3. שם הפרויקט: `birkat-avraham`. אפשר לכבות Google Analytics (לא נחוץ בשלב זה).
4. המתינו ~30 שניות עד שהפרויקט נוצר → **Continue**.

## שלב 2 — הוספת אפליקציית Web (2 דק')

1. במסך הפרויקט, לחצו על אייקון **`</>`** ("Add app" → Web).
2. כינוי: `birkat-avraham-web`. **אל** תסמנו "Firebase Hosting" כרגע (נעשה בהמשך).
3. יופיע בלוק קוד עם אובייקט `firebaseConfig` — יש בו 6 ערכים:

   ```js
   const firebaseConfig = {
     apiKey: "…",
     authDomain: "…",
     projectId: "…",
     storageBucket: "…",
     messagingSenderId: "…",
     appId: "…",
   }
   ```

   **⇒ שלחו לי את 6 הערכים האלה.** (הם מזהים ציבוריים — בטוח לשתף; האבטחה נאכפת
   בכללים, לא במפתחות.)

## שלב 3 — הפעלת Firestore (מסד הנתונים) (2 דק')

1. בתפריט הצד: **Build → Firestore Database → Create database**.
2. בחרו מיקום **`eur3` (europe-west)** — הכי קרוב לישראל.
3. התחילו ב-**Production mode** (אני מספק כללי אבטחה — הקובץ `firestore.rules`).

## שלב 4 — הפעלת Storage (לתמונות הגלריה) (2 דק')

1. **Build → Storage → Get started**. אותו מיקום (`eur3`).
2. הערה: Storage דורש תוכנית **Blaze** (תשלום-לפי-שימוש). למטה בשלב 7 — אל דאגה,
   העלות הצפויה לאתר בגודל כזה היא ₪0–5 לחודש.

## שלב 5 — הפעלת Authentication (כניסת גבאים) (3 דק')

1. **Build → Authentication → Get started**.
2. **Sign-in method → Email/Password → Enable → Save**.
3. **Users → Add user**: הוסיפו את הגבאים (אימייל + סיסמה זמנית). למשל:
   - `elad@birkatavraham.org.il`
   - `office@birkatavraham.org.il`

   **⇒ שלחו לי אילו אימיילים הוספתם** (כדי להגדיר להם הרשאת ניהול).

## שלב 6 — הרשאת ניהול (אני עושה, אתם מאשרים)

כדי שרק הגבאים יוכלו לערוך (וכולם יוכלו לצפות), אגדיר לחשבונות שלהם תגית `admin`.
זה נעשה פעם אחת דרך כלי צד-שרת. **מכם נדרש רק** לאשר את רשימת האימיילים משלב 5.

## שלב 7 — חיוב (Blaze) — אופציונלי אך מומלץ

- לוחצים על **Upgrade** (למטה משמאל) → בוחרים **Blaze**.
- מגדירים **תקרת תקציב (Budget alert)** של, נניח, ₪20/חודש כדי לישון בשקט.
- למה צריך: Storage לתמונות. אם בשלב ראשון אין תמונות אמיתיות — אפשר להישאר ב-Spark
  (חינם) ולדחות את זה. **⇒ עדכנו אותי אם אתם מעדיפים לדחות.**

## שלב 8 — Hosting + דומיין (בהמשך, יחד)

כשנגיע לעלייה לאוויר: `firebase init hosting` + `firebase deploy`, וחיבור הדומיין
(עם SSL אוטומטי חינם). זה שלב שנעשה יחד כשיהיה דומיין.
